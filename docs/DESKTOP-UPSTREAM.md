# Luna | Modified #377 Client

This is the official #377 client that connects to the [Luna game server](https://github.com/luna-rs/luna).

For the full list of modifications please see the [releases](https://github.com/luna-rs/luna-client/releases) section.

![](./data/media.png)

# Setup

Please see the [wiki](https://github.com/luna-rs/luna/wiki) for a full setup guide if you're looking to create your own world.

To play on Luna’s permanent world, [download the launcher](https://github.com/luna-rs/luna-client/releases/download/v0.5.0-alpha/luna-launcher.exe)
or [play in your desktop browser](https://luna-rs.github.io/luna-client/).
Enjoy faithful classic gameplay with 5× XP and no character wipes. Feedback and bug reports are welcome as you play.
For a source build, use the `beta.properties` profile to connect to the live world.

# Compatibility
Care was made not to make any changes to the #377 protocol.

You can still use a non-luna based #377 server with this client, and any faithful #377 client can connect
to Luna.
