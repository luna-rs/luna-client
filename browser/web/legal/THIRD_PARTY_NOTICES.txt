Florestan Basic GM GS soundbank
------------------------------
The inherited desktop asset data/soundbank.sf2 identifies itself in its embedded
RIFF INFO metadata as "Florestan Basic GM GS" and records "Public Domain" in its
ICOP field. Its embedded comment names these original project addresses:
  http://go.to/florestan
  http://nandoflorestan.cjb.net

The asset entered Luna client history in commit:
  bc622680122f8ab3d09aaf0ee8428b191055dca2

This records the asset's own metadata and provenance. Browser music uses the same
SoundFont as the desktop client; its packaged bytes are verified before playback.

Inherited client and game cache
-------------------------------
This repository retains the Luna revision 377 client source from its upstream
project:
  https://github.com/luna-rs/luna-client

Packaging requires a separately supplied compatible cache ZIP. The build
generates the cache seed and manifest locally; this source repository does not
distribute a game cache. The provenance and licensing limits below also apply
to inherited game assets and any cache used with a deployment.

The imported source includes legacy decompiled client headers and game assets.
The imported tree did not contain a project-wide LICENSE or NOTICE establishing
a blanket redistribution license for that code and cache. Existing notices are
retained. TeaVM's Apache license, ws's MIT license, and the SoundFont's metadata
must not be interpreted as licensing these other materials.

A private source repository does not make deployed assets private. Players receive
the browser JavaScript/WebAssembly, website artwork, configuration, and cache
files needed to run the client. Secrets and server private keys must remain
outside all published browser assets.
